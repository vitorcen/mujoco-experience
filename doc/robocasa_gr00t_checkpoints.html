TL;DR：RoboCasa 官方放出 5 档 GR00T N1.5 checkpoint，差异在 fine-tune 数据范围。本仓默认用 target_posttraining/atomic_seen/checkpoint-60000，atomic-seen 平均 success rate 68.5%，是单 7 GB 推理子集里最强的选项。要基于 N1.7 自训类似规模：仅 post-training ≈ ¥2,400-4,800（H800）/ ¥4,600-9,100（H20）；从头复刻 pretrain+posttrain ≈ ¥9,600-16,500（H800）/ ¥18,200-32,300（H20）。
RoboCasa ships 5 GR00T N1.5 checkpoints differing by fine-tune subset. We default to target_posttraining/atomic_seen/checkpoint-60000 (68.5% atomic-seen SR, 7 GB inference subset). Self-training a comparable N1.7 model: post-training only ≈ ¥2.4-4.8k on H800; full pretrain+posttrain ≈ ¥9.6-16.5k on H800.

1. 五档 Checkpoint 一览 (Five Checkpoints)

全部位于 HuggingFace robocasa/robocasa365_checkpoints repo（共 282 GB）。每档完整目录 ~16 GB（含 8.5 GB optimizer.pt 训练 resume 用）；本仓 只下推理子集 ~7.1 GB（model-*.safetensors + config + experiment_cfg）。

Checkpoint 路径 训练方式 覆盖任务 平均 SR 本仓推荐
multitask_learning/checkpoint-120000 纯 multitask 训练，所有任务一锅煮 全 300 任务（atomic + composite） 43.0% 通才 baseline
foundation_model_learning/pretraining/checkpoint-80000 大规模 pretraining（300 任务 + MimicGen 数据） 无 fine-tune，靠 generalization 41.9% 对照组
foundation_model_learning/target_only/atomic_seen/checkpoint-60000 只在 18 atomic-seen 数据上从头训 18 atomic-seen 50.6% —

foundation_model_learning/target_posttraining/composite_seen/checkpoint-60000 Pretrain → 再在 composite-seen fine-tune 16 composite-seen（长程任务） 40.6% 想跑长程任务再用
foundation_model_learning/target_posttraining/composite_unseen/checkpoint-60000 Pretrain → 再在 composite-unseen fine-tune 16 composite-unseen 42.1% 泛化测试用
关键洞察 / Key insight：post-training（pretrain + fine-tune）比 target-only（从头训）高 18 个百分点（68.5% vs 50.6%），证明 pretrain 阶段学到的物理常识 + 视觉表征确实有迁移价值。这是 GR00T 整套 foundation model 路线的核心实证。
Post-training (pretrain + fine-tune) beats target-only (from scratch) by 18 pts (68.5% vs 50.6%) — empirical proof that pretrain-learned physics priors + visual reps transfer.

3. 下载与使用 (Download & Usage)

本仓只下推理子集（砍掉 16 GB 里的 8.5 GB optimizer.pt、scheduler、rng_state、trainer_state），单 ckpt 7.1 GB：

from huggingface_hub import snapshot_download
ckpt = "gr00t_n1-5/foundation_model_learning/target_posttraining/atomic_seen/checkpoint-60000"
snapshot_download(
    repo_id="robocasa/robocasa365_checkpoints",
    repo_type="model",
    local_dir="~/.cache/robocasa/checkpoints",
    allow_patterns=[
        f"{ckpt}/model-*.safetensors",
        f"{ckpt}/model.safetensors.index.json",
        f"{ckpt}/config.json",
        f"{ckpt}/experiment_cfg/*",
    ],
)

4. 基于 GR00T N1.7 自训练 — GPU-hours 估算

NVIDIA 已发布 nvidia/GR00T-N1.7-3B 基座（2026-04-23），但没有 RoboCasa 任务专项 fine-tune。要拿到对应本仓 N1.5 的成功率（atomic-seen 68.5%），用户需自己复刻 pretrain + post-training pipeline。

4.1 模型规模 (Model Size)

  • GR00T N1.5/N1.7 backbone (Eagle2)：~3B params total
  • Action head (DiT diffusion)：~550M params
  • Self-attention transformer：~200M params
  • Backbone hidden_size：2048 / Action hidden_size：1024 / Action horizon：16

4.3 GPU-hours 推算 (Linus 式估算)

参考：3B VLA 模型 + 16-step action chunk + 224×224 三视角图像。H100 SXM5 典型吞吐 ≈ 5-8 steps/sec（含 backbone forward + DiT denoising 4-step）。H800（特供，NVLink 限速版）≈ H100 的 75-85%；H20（中国合规算力卡，FP16 算力大幅缩水）≈ H100 的 30-40%。

计算口径：取 H100 6 steps/sec 中位值；H800 ≈ 0.8× H100；H20 ≈ 0.35× H100。Batch 192 走 8 卡 data-parallel，单卡 forward 数等于 global steps。云价按 AutoDL 报价：H800 ¥9/GPU·h、H20 ¥8/GPU·h。阿里云灵骏 / 火山引擎机器学习平台 同卡型贵 3-5 倍（H800 ¥30-50/h），适合企业要发票，个人科研选 AutoDL。
H800 ≈ 0.8× H100 throughput; H20 ≈ 0.35× H100. Prices on AutoDL: H800 ¥9, H20 ¥8 per GPU·hour. Aliyun Lingjun / Volcano Engine charge 3-5× more.

If you already have the N1.7 base, post-training only takes ~1-2 days on 8×H800 (¥2.4-4.8k). Best value path.

4.5 自训练实际操作 (How to Actually Train)

  1. 拉 fork：git clone https://github.com/robocasa-benchmark/Isaac-GR00T（本仓已作为 submodule 在 dependencies/Isaac-GR00T/）
  2. 装环境：pip install -e .[base] + flash-attn==2.7.1.post4（见 scripts/install_gr00t_env.sh）
  3. 下数据：python -m robocasa.scripts.download_datasets --tasks <atomic_seen>（每个任务几 GB，18 任务 ~50-100 GB）
  4. 训： 
    python scripts/gr00t_finetune.py \
  --output-dir /path/to/output \
  --dataset_soup atomic_seen \
  --max_steps 60000 \
  --base-model nvidia/GR00T-N1.7-3B   # 改 base 即可切换 N1.5 → N1.7
  5. eval：python scripts/run_eval.py --model_path <your-ckpt> --task_set atomic_seen --split pretrain — 或直接复用本仓 scripts/robocasa_eval_gr00t.py
